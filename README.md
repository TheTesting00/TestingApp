# MySmile (TestingApp)

Aplikasi pemutar musik Android yang bersih dan mudah digunakan di HP, dengan tampilan utama minimalis, pemutar musik popup otomatis saat memutar lagu, dan seluruh fitur lanjutan terintegrasi rapi di **menu titik 3 (⋮)**.

## Fitur Utama

### 1. Tampilan Depan Minimalis & Fokus
- **Daftar Musik Luas & Bersih:** Tanpa tombol-tombol yang memadati layar depan.
- **Pencarian Cepat & Filter:** Cari berdasarkan judul lagu, artis, atau album, dengan filter *Semua*, *Diedit*, dan *Berlirik*.
- **Pemutar Musik Popup (Mini Player):** Melayang otomatis di bagian bawah saat musik diputar. Ketuk untuk membuka layar pemutar penuh (*Now Playing*).

### 2. Menu Pengaturan Titik 3 (⋮) Lengkap
Semua fitur dan alat lanjutan dapat diakses dari satu tempat:
- ➕ **Tambah File Musik:** Pilih file audio langsung dari penyimpanan HP.
- ✏️ **Edit Musik & Cover:** Ubah judul, artis, album, ganti foto cover dari galeri, potong durasi lagu, atur tempo (`0.5x`–`2.0x`), nada (*pitch*), dan edit lirik (`.txt` / `.lrc`).
- 🎧 **Studio Earphone:** Deteksi otomatis saat earphone kabel atau TWS Bluetooth tersambung. Dilengkapi Equalizer 5-Band, Bass Boost, Surround 3D, Loudness Gain, auto-pause saat dilepas, dan gestur tombol headset.
- 🎨 **Tema & Tampilan:** 6 pilihan tema warna keren (*Midnight Emerald, Neon Cyber, Glass Aurora, Sunset Bold, Rose Velvet, Minimal Clean*).
- ⏱️ **Timer Pemutar Musik:** Pengatur waktu tidur (*sleep timer*) dengan preset menit, mode berhenti di akhir lagu, dan efek fade-out lembut.
- 🔒 **Private File & Video (Fitur Baru):**
  - Brankas terproteksi **PIN 4-Digit** untuk menyimpan file dan video rahasia secara aman di penyimpanan internal terisolasi.
  - Mendukung penambahan video dan file/dokumen pribadi.
  - Dilengkapi pemutar video langsung (*built-in video player*) di dalam aplikasi.
- 🔄 **Muat Ulang Lagu:** Memindai ulang audio di perangkat.

## Cara Mengunduh File `.apk` dari GitHub
1. Buka tab **Actions** di repositori GitHub: [TheTesting00/TestingApp](https://github.com/TheTesting00/TestingApp).
2. Klik workflow **Build Android APK** terbaru yang berstatus hijau.
3. Gulir ke **Artifacts**, unduh **MySmile-debug-apk**, ekstrak `.zip`-nya, lalu install `app-debug.apk` di HP Android kamu.
